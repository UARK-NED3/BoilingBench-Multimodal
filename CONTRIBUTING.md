# Contributing to BoilingBench-Multimodal

BoilingBench-Multimodal is intended to grow through community contributions. Please contribute by opening a GitHub issue or pull request with:

1. Dataset title, authors, institution, and contact.
2. Persistent dataset DOI or planned archive location.
3. Modalities, S+TD class, and file formats.
4. Physical metadata: fluid, pressure, geometry, surface, heat flux, mass flux if applicable, sensor layout, calibration, and uncertainty.
5. Proposed benchmark task and target labels.
6. Proposed split logic and leakage risks.
7. License and reuse constraints.
8. Baseline script or minimal loader where possible.

Raw data should be archived in Zenodo, Dataverse, Dryad, institutional storage, Globus, or another data repository. Do not submit large raw data files directly to GitHub.
