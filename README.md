# BoilingBench-Multimodal

BoilingBench-Multimodal is an NED³ benchmark and dataset family for machine learning, computer vision, and multimodal analysis of boiling and two-phase thermal systems. It combines synchronized measurements, BoilingLab-derived annotations, human image annotations, and single-modality reference datasets.

This repository is the benchmark control plane: dataset cards, schemas, manifests, task definitions, split rules, validation scripts, and reproducibility documentation. Large raw archives are not committed to Git; distribute them through an archival repository or approved Hugging Face revision with checksums and a DOI where available.

Detailed cards in [`docs/datasets/`](docs/datasets/) define file inventories, units, provenance, processing, limitations, and citations. Each external dataset directory also contains a dataset-local `README.md`.

## Evidence and annotation conventions

BoilingBench-1--4 contain measured signals plus derived heat flux, surface temperature, event times, spectra, synchronization offsets, regime indicators, and hysteresis products generated by BoilingLab. Derived products are not independent measurements. Verify thermocouple geometry, material properties, calibration, pressure, and missing channels before treating them as quantitative ground truth.

BoilingBench-5 human labels must remain distinguishable from machine-generated labels. Model weights may have separate licensing. BoilingBench-6 and -7 are deliberately single-modality tracks.

## Recommended tasks and splits

Supported tasks include heat-flux regression, regime/transition classification, bubble segmentation and morphology, cross-condition generalization, missing-modality robustness, and physics-informed uncertainty-aware prediction. Never split adjacent windows from one run across train, validation, and test. Prefer run-, surface-, heat-load-path-, or dataset-held-out evaluation, with preprocessing fitted on training data only.

## Release, citation, and licensing

This benchmark is the data-and-task layer in the NED³ AI-for-thermal
ecosystem. [Thermal AI Commons](https://github.com/UARK-NED3/Thermal-AI-Commons)
provides shared contracts, synchronization/provenance records, compatibility
pinning, benchmark splits, and evidence reports; [BoilingLab](https://github.com/UARK-NED3/BoilingLab),
[BubbleID](https://github.com/cldunlap73/BubbleID),
[BubbleID-Flow](https://github.com/UARK-NED3/BubbleID-Flow), and
[SeqReg](https://github.com/cldunlap73/SeqReg) remain independently released
processing, feature-extraction, and sequence-learning components.

The public Lite data snapshot is distributed through Hugging Face and archived on Zenodo. The control-plane release below binds the three records together:

- **GitHub control repository/release:** [`v0.1.0`](https://github.com/UARK-NED3/BoilingBench-Multimodal/releases/tag/v0.1.0)
- **Hugging Face data profile:** [BoilingBench-Multimodal](https://huggingface.co/datasets/hanhuark/BoilingBench-Multimodal)
